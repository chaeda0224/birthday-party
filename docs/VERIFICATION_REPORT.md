# 생일 파티 v0.1.2 독립 검증

검증: GPT-6.1 Sol · 2026-11-06 · [변경 기록](../CHANGELOG.md): 입김·공동 소등, 촛불 나이 설정, 사진 배치, 자이로 반응.

**판정: CI·테스트 배포 후보에 적합. v0.1.2 최종 실기기 판정은 보류.** 마지막 독립 실행에서 타입 검사와 테스트 22/22(8+14)가 통과했다. 최종 배포 후보의 타입·22개 테스트·빌드 재실행은 예정 상태이며 이번 문서 갱신에서 실행하지 않았다.

- **종료·음향 — 독립 확인:** 종료 뒤 늦은 RPC가 프로필을 되살리지 않는 회귀를 통과했다. 음향 중지 뒤 재준비가 들어오면 불기 전환이 거부된다. 재개 후 현재 제어 버전의 중지 ACK를 보내면 게스트의 입김 한 번으로 소등되는 것을 PGlite에서 확인했다. [PartySession:53](../src/app/PartySession.tsx#L53)에서 재개 시 ACK 전송을 확인했다. 일시정지 때 마이크가 정지하므로 재개 뒤 사용자가 다시 켜는 흐름이 정상이다.
- **실 API·사진 — 통합 담당 전달:** 방 계약 10건 통과. 실제 Edge에 도형 사진 업로드·조회·삭제(프로필 참조 제거) 통과. 이번 독립 검증에서는 실 API를 재호출하지 않았다.
- **사진 정리 — 실 엔드포인트 정상 응답, 객체 회수 미확인:** 0005 적용 뒤 정리 호출은 HTTP 200, `{status: "checked", removed: 0}`으로 응답했다. 5분 간격 Cron 작업 1개가 등록됐다. 해당 호출에서 실제 객체 삭제는 0건이며, 작업 등록 자체는 예약 실행이나 물리 삭제를 입증하지 않는다.

**남은 확인:** 이전 버전에서 “불어도 안 꺼짐”을 실제 휴대폰에서 확인했고, 감지 기준과 첫 입김 소등을 바꾼 수정본은 같은 휴대폰에서 사용자 재확인 대기 중이다. 실기기 10대 동기화, 실제 자이로 입력, 사진 서명 URL의 전체 TTL 및 만료 차단, 예약 작업의 실제 객체 삭제는 아직 확인하지 않았다. 원계약 QA 46개 전체를 통과했다는 의미가 아니다.
