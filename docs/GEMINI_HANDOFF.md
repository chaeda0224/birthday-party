# Gemini 후속 점검

이 저장소의 최종 커밋을 기준으로 검토합니다. PLAN.md의 2D 방향은 사용자의 후속 요청인 검은 배경·고급스러운 3D 촛불 연출로 변경됐습니다. 실제 사진이나 개인정보를 시험 자료로 만들지 않습니다.

1. `npm ci` 후 타입·단위·장치 모듈·Postgres 엔진·빌드를 실행합니다.
2. 폰 한 대의 설정부터 종료, 태블릿 없이 두 대 이상 공동 입장과 단계 전파를 확인합니다.
3. 마이크 허용·거절·늦은 허용 응답·탭 숨김·기기 잠금, 흔들기 미지원 버튼 대안을 실기기에서 확인합니다.
4. 소리 담당 한 대, 불기 단계 무음, 종료 후 마이크 해제, 사진 교체·삭제·만료와 다른 방 접근 거부를 확인합니다.
5. WebGL 실패 대안과 3D 조명·사진 토퍼, 검은 화면의 글자 대비, 모바일 잘림, 한글 줄바꿈을 점검합니다.
6. 서버 SQL의 CAS·요청 중복·회차·호스트 유효기간, 이전 음향 기기의 권한 만료, 사진 정리 경합을 검토합니다.

자동 시험과 실제 기기 결과를 구분하고 파일·줄·재현 절차를 남깁니다. 실제 기기 시험 전 QA 전체 통과로 표시하지 않습니다. 보고서에는 토큰·원음·사진·연락처를 넣지 않습니다.
