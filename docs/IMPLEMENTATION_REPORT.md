# 구현 및 배포 기록

2026-11-06 · v0.1.2 · 공개 저장소와 GitHub Pages 배포

## 반영한 기능

- 휴대폰 한 대와 여러 기기의 공동 방. 태블릿은 선택 사항.
- 이름·월일·남성/여성/공통 연출·호칭·대사·케이크 테마·사진 편집.
- 긴 촛불 10살, 짧은 촛불 1살의 개수 선택. 사진 토퍼·배경·둘 다.
- 검은 배경의 Three.js 케이크와 크게 보이는 촛불, 금색 조작부, 연기·폭죽·짧은 합성음.
- 실제 동작·마이크·방향 센서 연결, 권한 요청과 정리, 버튼 대안. 사용자 기기 입김 실패 피드백에 따라 마이크 주파수 범위·문턱·보정 시간을 수정.
- 한 참여 기기의 불기 감지가 방 전체 소등으로 전환. 역할·회차·상태 버전·종료 경합 처리.
- Supabase 익명 인증·RLS·RPC·사진 검증 Edge 함수·private Storage. 5분 주기 정리 작업 등록.

## 확인한 범위

- TypeScript·운영 빌드·작성 코드 점검 통과. Three.js 별도 청크는 압축 전 500KB 경고가 있으나 빌드 오류는 없음.
- 상태·PGlite·방향 입력 테스트 8개, 장치·정적 계약 테스트 14개 통과.
- 실제 Supabase 익명 인증·방 생성/참여·프로필 공유·직접 쓰기 거부·기여·소등·재축하·종료 접근 차단 10개 흐름 통과.
- 실제 사진 Edge의 도형 PNG 검증·WASM 재인코딩·비공개 서명 읽기·참조 삭제 통과. 모든 형식과 큰 파일 경계를 실호스팅에서 다 시험한 것은 아님.
- 정리 트리거를 실제 호출해 HTTP 200과 정상 상태를 확인. 삭제할 작업 0개 응답이므로 이 호출로 실제 객체 회수까지 입증한 것은 아님.
- 데스크톱 Chrome에서 단독 파티 흐름과 390px 화면, 긴/짧은 촛불 설정·WebGL 렌더를 확인.
- Sol 지정 독립 검토의 종료 지연 응답 복원과 음향 ACK 재사용 문제를 수정. 최종 판단은 VERIFICATION_REPORT.md 참고.

## 남은 확인

사용자가 실패를 보고한 실제 휴대폰의 수정본 마이크 재시험, iPhone/iPad/Android별 자이로·흔들기 권한과 동작, 실제 3대·10대 동시성과 500ms 폭죽 편차는 완료로 표시하지 않는다. 시뮬레이션 브라우저와 PGlite는 실기기를 대체하지 않는다. `scripts/e2e.mjs`는 재실행 가능한 자동 시험이며, 이 기록의 수동 브라우저 확인과 구분한다.

hangul-wrap의 실행 스크립트가 설치 경로에 없어 해당 자동 측정은 실행하지 못했다. 브라우저에서 좁은 화면을 직접 확인했으며 한글 실측 전체 통과라고 주장하지 않는다. trail check도 CLI가 저장소를 인식하지 못해 완료하지 못했다.

## 공개·개인정보

소스·빌드 설정·문서·시험 코드만 커밋했다. 로컬 공개 연결 설정, 인증 세션, 실제 인물 사진, 사용자 프로필, 브라우저 캡처와 운영 초대 링크는 커밋하지 않는다. 자체 텍스트 형식 검사에서 작성 파일의 후보가 없었으며, 의존 패키지의 필수 고지·캐시와 바이너리·이미지·PCFilter는 별도 범위다. 운영 서비스가 자체 기록하는 접속 로그까지 차단했다고 주장하지 않는다.

초기 설계는 Astra 지정 검토, 구현은 Luna 병렬 작업과 부모 통합, 독립 코드 검토는 Sol 지정 에이전트로 수행했다. UI 작업 지연으로 부모가 App·스타일과 상태 통합을 인계받았고 이를 작업 중 알렸다. 3D와 방향 센서는 별도 Luna 작업으로 추가했다.
