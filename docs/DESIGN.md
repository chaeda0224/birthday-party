# 촛불 중심 3D 화면

2026-11-06 사용자 후속 요청이 최초 2D 기획보다 우선한다.

검은 배경, 샴페인 골드 조작부, 촛불 중심의 3D 구도를 사용한다. 촛불이 화면 중앙을 채우고 케이크는 아래쪽에 둔다. 불꽃은 심지를 고정한 채 상단을 휘게 하고 빛의 강도와 주변 반사를 함께 변화시킨다. 기기의 기울기에 맞춰 카메라와 불꽃 방향을 부드럽게 조절한다.

긴 촛불은 10살, 짧은 촛불은 1살이다. 출생연도에서 계산하지 않고 사용자가 직접 개수를 선택한다. 사진은 케이크 토퍼·전체 배경·둘 다를 선택하며, 배경에는 어두운 겹침을 적용한다.

원래의 장난스러운 성격은 마지막 촛불과 짧은 문구·소리로 유지하고, 장난감 표정과 사무용 대시보드 구조는 사용하지 않는다. 명암·소리·자이로·마이크를 각각 제어할 수 있게 한다. 움직임 줄이기는 파티 규칙을 바꾸지 않는다.

참고: [Candle HD](https://apps.apple.com/us/app/candle-hd-relaxing-flame/id897880341)의 몰입형 불꽃, [Soonsoon Candle Light](https://apps.apple.com/us/app/soonsoon-candle-light/id1175954964)의 검은 배경, [A Small Flame](https://play.google.com/store/apps/details?id=software.fixedpoint.asmallflame)의 주변광과 3D 질감. 이미지·코드를 복제하지 않고 화면 특성을 참고했다.

실제 WebGL 렌더를 확인하고 불꽃 소등과 사진 표시는 기능 시험으로 별도 확인한다. 실기기 센서 검증은 데스크톱 시뮬레이션으로 대체하지 않는다.
